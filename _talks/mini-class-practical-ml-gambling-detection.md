Honored to facilitate a Mini Class on Practical Machine Learning from August 24–27, 2026, titled "Build an AI System to Detect Comments Promoting 
Online Gambling Using Machine Learning in 4 Days". The session guided participants through the practical process of building a Machine Learning system, 
starting with Data Preparation and Exploratory Data Analysis (EDA) to prepare and understand the characteristics of the data. The discussion continued 
with building and optimizing a Machine Learning model to detect comments promoting online gambling and evaluate its performance. Participants also learned 
how to deploy the trained model using Streamlit and transform it into a simple, practical application.
